## 一、Demo 与试玩说明

### 1.1 如何打开

| 方式 | 步骤 |
|---|---|
| **网页链接（推荐）** | 打开 https://1986772315h-ui.github.io/base_work/m98/ |
| **本地文件** | 双击 `M98_原型.html`，或右键「打开方式 → 浏览器」 |

- 无需安装、无需联网（本地文件）、无需服务器、无需编辑器。
- 技术形态：**单个 HTML 文件**，原生 HTML/CSS/JS，无框架、无构建产物依赖，角色立绘以 base64 内联。
- 兼容：Chrome / Edge / Firefox 等现代浏览器。**建议窗口宽度 ≥ 1150px**（两栏布局）；窄屏自动堆叠为单列，功能不受影响。
- 无存档，刷新页面即从头开始；右上角 `重置` 亦可清空进度。

### 1.2 界面结构

首次进入时，界面上**只有一张关卡卡片和一个「挑战」按钮**。打完第一关会先看到结算，点「返回关卡」之后，左侧才出现角色养成卡牌。

```
┌──────────────────────────────────────────────────────────────┐
│                                                          重置 │
├──────────────────────────────────┬───────────────────────────┤
│ 改造者          [改装件][躯体材料] │  章节页签                  │
│ 立绘 + 三张部位标注卡（带引线）     │  关卡列表 / 战斗结算 / 部位 │
└──────────────────────────────────┴───────────────────────────┘
```

- **左＝角色养成卡牌，右＝上下文面板**。两种货币在角色卡的右上角。
- 右栏在三种状态间切换：**关卡列表**（默认）、**战斗结算**（点挑战后）、**部位面板**（点立绘上的部位后）。

### 1.3 操作说明

**① 挑战关卡**
点 `挑战` → **直接出结算**（不播放逐条战斗过程）。`再战` 重打同一关，`← 返回关卡` 回列表。

- 通过后材料**自动入账**并提示「奖励已领取」，无需手动领取。
- **只有首通给奖励**：普通关 +1 改装件；1-E +3 改装件 + 2 躯体材料；2-E +3 改装件 + 1 躯体材料；**3-E 为最终关，不给奖励**。
- **章节页签**可切换查看。点**未开放**的章节不会切进去，会提示需要先通关上一章节。

**战斗规则**：每回合改造者只做一件事——攻击（重拳）或防御（硬抗）。自动演算，行为规则固定：

> 本回合敌人发动重击，或硬抗的持续护盾已结束 → 防御；否则 → 攻击。

我方护盾**跨回合累积**。**战斗完全无随机**：同一关、同一配装，结果永远一致。

**敌人行动循环**（关卡卡片与结算顶部都有）：
`⚔️18` 普通攻击 · `🔪3×6` 多段攻击 · `🪓破甲 30` **破甲（无视护盾与减伤，直接扣血）** · `⏳蓄力` 本回合不攻击 · `⚡重击 78` 高额一击 · `⚠️1` 附带 1 层干扰 · `🛡️每回合 26` 每回合刷新护盾；`›` 分隔回合，`↻` 表示循环。

**② 读结算（定位卡点的主要手段）**

结算分五块：结果横幅 → **我的输出去向** → **我承受的伤害来源** → 血量变化曲线 → 其它记录。

两根堆叠条是核心：
- **我的输出去向**：`打在本体上` / `用于击破护盾` / `被干扰削减`
- **我承受的伤害来源**：`破甲直击生命` / `常规扣除生命` / `被护盾吸收` / `被缓冲抵消`

占比最大的一段会自动高亮。**与本局无关的项不显示**（没带净化芯片就不会出现"清除减益层数"；敌人没有破甲就不会出现"破甲直击生命"）；但「打在本体上」「常规扣除生命」即便为 0 也保留——0 本身就是结论。

血量曲线**纵轴为生命值、横轴为回合数**（均有轴标题与刻度），节点上标注该回合出现的效果图标，且效果标记按侧分离。

**③ 打开某个部位**
点立绘上的**圆点**或旁边的**标注卡**（标注卡上直接写着该部位主动技能的当前数值）。关闭：点 `关闭`，或点击左侧养成区空白处。

**④ 改造**

| 操作 | 说明 |
|---|---|
| 主动技能 `强化` | 手臂＝重拳、躯干＝硬抗，**固定不可替换**；消耗改装件 2 / 3 / 4，最高 Lv.4 |
| 被动栏 `+1 格` | **手臂 1 格（开局已开）、躯干 1 格、头脑 2 格**；开槽消耗 1 躯体材料 |
| 被动芯片 | 开局**全部未解锁**。`解锁` → `安装` / `卸下`；`强化` 到 Lv.2 消耗 1 改装件（解锁后不装也能强化） |
| `↺ 重置XX养成` | 面板底部红色按钮，该部位恢复初始并**全额返还**投入过的材料 |

**强化确认就在卡片里**：点 `强化` 后卡内出现 `项目 旧值 → 新值` 与 `取消 / 确认 / 消耗 [改]n /持有量`，不弹窗；余额不足时数字变红、`确认` 置灰。

**读法**：槽位——带图标的格 = 已装（角标为等级）、白格 = 空闲、斜纹 🔒 格 = 未开放；芯片卡——虚线框 + 灰图标 + 🔒 = 未解锁、白底实线框 = 已解锁、部位色描边 + `✓ 已装备` = 已装备。卡片默认**只显示当前等级的效果**。

### 1.4 试玩建议路径（第一章约 5 分钟）

1. 直接点 **1-1** 挑战，默认就能过。看完结算点「返回关卡」，注意左侧出现了养成板块。
2. 再打 **1-2**。会输——**重点看结算第一根条：`打在本体上 0`**。
3. 自己判断该买什么，然后回 1-2 验证。（手臂只有 1 格，所以"这一格给谁"是唯一的问题。）
4. 通过第一章后进第二章，注意关卡卡片上多出来的 `🪓破甲` 标记；打一场，看结算里 `破甲直击生命` 那一段有多长。
5. 想体验"半成品"的手感：2-1 只把硬抗升级就去打——会输，而且「被护盾吸收」依然只有一小段。
6. 第三章的敌人开始叠干扰，第一根条里会多出 `被干扰削减`。

**给主持试玩的人**：请**不要口头提示"该买哪张芯片"**。本题要观察的正是"玩家能否只凭结算的两根条自己得出下一步"。

## 二、设计说明

### 2.1 目标玩家、初始处境、一开始能看到的信息

**目标玩家**：喜欢配装 / build 乐趣、能接受自动战斗、享受"看数字找出问题"的轻度策略玩家。

**初始处境**：重拳 Lv.1、硬抗 Lv.1；**没有任何芯片被解锁或装备**；手臂 1 格是开放的，躯干与头脑 cost 上限为 0；持有 3 改装件、0 躯体材料。只有 1-1 开放。

**一开始能看到的全部信息**：**只有一张关卡卡片和一个「挑战」按钮**——没有属性面板、没有养成板块、没有章节页签。关卡卡片上写着敌人 HP 与行动循环（`⚔️9`）。

**通过 1-1 并返回后**，信息一次性展开：

| 位置 | 内容 |
|---|---|
| 角色卡（左） | 立绘 + 三张部位标注卡：`已用 / 上限`、该部位主动技能与**当前数值**、槽位格；右上角是两种货币余额 |
| 部位面板 | 主动技能卡（当前效果 + 强化价格）、被动栏槽位、该部位全部芯片（当前效果、价格、状态）、重置按钮与可返还量 |
| 关卡列表（右） | 章节页签（进度 / 是否开放）+ 当前章 3 关：HP、敌人行动循环、首通奖励、开放状态 |
| 战斗结算 | 输出去向 / 承伤来源两根堆叠条、双方血量曲线、非零的其它记录 |

> 以上全部是**状态与结果描述**。所有选项都标注价格，但不会标注"推荐"；没有任何祈使句、红点、箭头或"下一步"字样。

### 2.2 目标感是怎么产生的

题目的判定标准是：**玩家不看任何"下一步提示"，只凭界面上的资源、状态变化和可交互元素，能否自己推断出一个可能的目标。** 本方案的回答是四段式：

**第一段 · 先给问题，再给工具（渐进式展开）**
首次进入没有任何养成入口，玩家的第一个动作必然是"打一场"，而不是"研究面板"。等他看到养成板块时，他已经知道自己在为什么而养成。

**第二段 · 卡点可读（数据不是建议）**
结算去掉逐条过程，直接给两根堆叠条。
- 打 1-2 失败时看到的是 `输出 140 点 → 用于击破护盾 140（100%），打在本体上 0（0%）`，配上敌人那条**一路平直的血量曲线**。
- 进第二章失败时看到的是 `承受 153 点 → 破甲直击生命 90（59%）`，而「被缓冲抵消」这一项**根本不出现**（没带，也用不上）。

→ 全程没有一句"建议携带破阵模块"，但问题在哪是明确的。

**第三段 · 手段可见（能力不是指引）**
点开任一部位，即可看到主动技能的当前效果与强化价格、被动栏只有几格、该部位全部芯片的效果/价格/状态。玩家会把第二段与第三段连起来："破阵对护盾 ×2——那我是不是就能打穿了？"

**第四段 · 岔路真实（取舍不是伪装）**
手臂那一格：破盾还是吸血。躯干那一格：回血还是反打。头脑两格：净化、减伤、增伤里选两个。
**能说出"我选 B，因为我放弃了 A"——这就是自发目标的现场证据。** 重置按钮保证这个选择可以反悔，代价为 0。

**闭环如何合上**：改造后再打同一关 → 通过 → 材料自动入账 → 下一关开放，新敌人的行动循环直接摆在关卡卡片上（第二章第一关就写着 `🪓破甲 30`）→ 玩家带着新问题进入下一轮。

**两个方向的落实（对应题目要求 2）**

| 方向 | 实现程度 |
|---|---|
| **机制路线（对症芯片）** | **完整实现**：1-2 失败 → 读结算 → 解锁破阵 → 通过 → 1-E 暴露新卡点。全 9 关每关都有对症解 |
| **数值路线（强化主动技能）** | **完整可玩**：重拳/硬抗各 4 级，1-E、2-E 可仅靠重拳 Lv.2 通过；两条路线抢同一份改装件 |
| **扩槽方向（开哪个部位）** | **完整实现**：躯体材料只从精英关产出，总量与待开槽位数严格相等，"先开躯干还是先开头脑"是真实决策 |

### 2.3 系统与数值

**结构**

| 部位 | 定位 | 主动技能（固定，可强化 3 次） | 被动栏 | 被动芯片（cost 1/张，可强化 1 次） |
|---|---|---|---|---|
| 手臂 | 攻击 | 👊 重拳 20/26/33/41 | **1 格**（开局已开） | 💥 破阵模块 对盾×2/×3（解锁价 **1**）· 🩸 汲能回路 吸血 30%/50% |
| 躯干 | 承伤 | 🛡️ 硬抗 立即 12/16/20/25 + 之后 3 回合每回合 5/7/9/11 | **1 格** | 💚 生体再生 获盾回 6/10 · 🌵 反应装甲 反伤 5/8 |
| 头脑 | 辅助 | — | **2 格** | ✨ 凝神 +6%/+10% 每层（上限 5 层）· 🧹 滤波 清 1/2 层减益 · 🧱 缓冲模块 持盾 −25%/−40% |

主动强化消耗改装件 2/3/4；被动解锁 2 改装件（破阵 1）、强化 1 改装件；扩槽 1 躯体材料。

**战斗结算规则**

| 项 | 规则 |
|---|---|
| 形式 | 回合制自动战斗，改造者先行动，**每回合只执行攻击或防御之一**，上限 15 回合 |
| 回合顺序 | 回合开始（硬抗持续护盾、敌方护盾刷新）→ 改造者行动 → 敌方行动 → 回合末（滤波） |
| 改造者生命 | 100 |
| 重拳伤害 | `floor( 重拳基础值 × (1 + 凝神层数 × 凝神%) × (1 − 干扰层数 × 15%) )` |
| 敌方护盾 | 每回合开始**刷新**为固定值；重拳先打护盾，破阵使护盾承受 ×2/×3 伤害，击穿后余量打本体 |
| 我方护盾 | 由硬抗获得，**跨回合累积**；敌人伤害先扣护盾再扣血 |
| 受击顺序 | 缓冲模块减伤（仅持盾时）→ 扣我方护盾 → 扣血 → 反应装甲反伤 |
| **破甲** | 敌方破甲攻击**无视我方护盾与缓冲模块，直接扣血**（反应装甲的反伤仍触发） |
| 敌人重击 | 前一回合蓄力（不攻击），下一回合高额单发；改造者在重击回合固定防御 |
| 干扰 | 每层使改造者伤害 −15%，上限 5 层；滤波每回合末清除 1/2 层 |
| 胜负 | 敌人 HP 归零＝胜；改造者 HP 归零＝负；15 回合未分胜负＝负 |

**关卡与考点**

|---|---|---|---|---|---|---|
| 1-1 巡逻无人机 | 普通 | 90 | — | ⚔️9 | 熟悉操作 | 默认可过（R7） |
| 1-2 盾卫哨兵 | 普通 | 42 | 26 | ⚔️18 | **护盾** | 破阵模块（R8） |
| 1-E 蜂群母舰 | 精英 | 60 | 28 | ⚔️18 › ⚔️18 › 🔪2×9 | 护盾加码 | 破阵²（R8）或 重拳2+破阵（R8） |
| 2-1 碎甲工兵 | 普通 | 102 | 8 | ⚔️21 › 🪓破甲 30 | **破甲** | 生体再生（R8） |
| 2-2 链锯猎犬 | 普通 | 112 | 10 | 🪓破甲 3×6 | 连续破甲 | 再生²（R10）**或 反应装甲（R5）** |
| 2-E 攻城执行者 | 精英 | 80 | 10 | ⚔️21 › 🔪3×12 › ⏳ › ⚡重击破甲 78 | 破甲 + 爆发 | 再生²（R7） |
| 3-1 信号干扰者 | 普通 | 120 | — | ⚔️27 ⚠️1 | **干扰** | 滤波（R8） |
| 3-2 电磁压制者 | 普通 | 140 | — | ⚔️33 ⚠️1 | 高额单发 + 干扰 | 缓冲模块（R10） |
| 3-E 中枢主脑 | 精英 | 110 | 10 | ⚔️20 ⚠️2 › 🔪3×9 ⚠️1 › ⏳ › ⚡重击破甲 63 | 三者叠加 | 滤波 + 缓冲（R11） |

**章节考点**：第一章＝护盾（手臂）；第二章＝破甲（躯干）；第三章＝减益（头脑）。第一章精英与第二章普通关**都保留护盾**，所以破阵模块不会在一关之后就被淘汰。

**半成品必败**（差距会在结算里显示为"差多少"）：1-E 只有破阵 Lv.1；2-1 只升硬抗（对破甲完全无效）；2-2 只有再生 Lv.1；3-1 只装凝神；3-2 只升硬抗 Lv.2；3-E 缺滤波或缺缓冲。

**经济总账**

| 来源 | 改装件 | 躯体材料 |
|---|---|---|
| 开局 | 3 | 0 |
| 普通关首通（6 关） | +1 / 关 | 0 |
| 1-E 首通 | +3 | +2 |
| 2-E 首通 | +3 | **+1** |
| 3-E 首通（最终关） | **0** | **0** |
| 重复通关 | 0 | 0 |

全程可得改装件 15、躯体材料 **3**；而躯干 1 格 + 头脑 2 格正好需要 3 个——**躯体材料零余量**，一格都不能开错（开错用部位重置全额拿回）。对症路线实际支出约 9 改装件、3 躯体材料。

### 2.4 在哪些方向之间做了取舍

| 取舍 | 选择 | 理由 |
|---|---|---|
| 首次进入展示什么 | **只有一个关卡和一个挑战按钮** | 先让玩家撞上问题，再把工具交给他；避免一上来就面对三个部位的面板 |
| 战斗过程 | **只给结算，不播过程** | 逐条日志字太多玩家不读；把预算全部投到结算的可读性上 |
| 卡点怎么呈现 | **输出去向 / 承伤来源两根堆叠条** | 纯总览容易"抽象"，堆叠条把"我的伤害去哪了、我的血怎么掉的"变成一眼能读的比例 |
| 零值指标 | **与本局无关的项不显示** | 没带净化芯片就不该看到干扰指标；但"本体命中 0"要保留，它就是结论 |
| 主动技能是否可替换 | **固定，只能强化** | 把"选什么"的决策全部集中到被动栏；主动只承担"基本功" |
| 每回合行动数 | **攻击或防御二选一** | 防御有真实的机会成本（少打一次），护盾类芯片的价值因此可被感知 |
| 手臂 / 躯干槽位 | **各只有 1 格** | 把配装压缩成"这一格给谁"，每章都必须正面回答 |
| 被动等级 | **只有 Lv.1 → Lv.2** | 被动的决策在"装哪张"，强化一次就是"补满" |
| 开局是否送芯片 | **不送，全部未解锁** | 第一张芯片必须是玩家自己决定买的 |
| 主动强化用哪种资源 | **改装件** | 与芯片抢同一份预算，形成"基本功 vs 新效果"的直接对立 |
| 躯体材料从哪来 | **只从精英关，且逐章递减 2/1/0** | 扩槽节奏被章节门槛锁住；总量与待开槽位数严格相等 |
| 关卡奖励 | **仅首通** | 断掉"刷一刷就有钱"的退路，让每次投入都要想清楚 |
| 错误投资 | **部位重置全额返还，按钮做得显眼** | 仅首通奖励会放大试错代价，重置把代价归零，同时作为死局保护 |
| 破甲机制 | **无视护盾与缓冲** | 让第一章学到的"堆护盾"在第二章明确失效，制造类型性的换答案时刻 |
| 随机性 | **完全移除** | 同配装结果恒定，玩家能干净地对比改造前后的差异 |
| 未开放章节 | **可见但点不进，给出原因** | 让玩家能提前看到后面的敌人（规划信息），但不产生"能打却打不了"的困惑 |
| 战斗手动 vs 自动 | **自动 + 固定行为规则** | 题目只要养成目标感；固定规则让"为什么打不过"只取决于配装 |

**参考来源**

- 《背包乱斗》：空间约束下的取舍快感——本方案把"背包格子"换成"部位 cost 上限"，并压到每部位 1–2 格。
- 《杀戮尖塔》：敌人意图公开 + 卡点的"可读性"——让玩家从敌人行动与战斗数据里自己找出 build 缺口。
- 《鬼谷八荒》《了不起的修仙模拟器》：短周期养成的节奏压缩，用预设状态跳过中间回合。
- 自身体验：早期版本把战斗做成逐条日志流，自己复读时就会跳过；这直接导致本版把"过程"整体删掉、把预算压到结算的两根堆叠条上。

以下都是在自查/自玩中发现并已改掉的，按发现顺序：

| # | 发现的问题 | 做了什么修改 |
|---|---|---|
| 1 | 早期结算是逐条战斗日志，自己复读时就会跳过，信息密度低且看不出结论 | **删掉整个过程展示**，改为挑战后直接出总览 |

| 3 | 结算里会出现一堆与本局无关的 0 值指标（没带干扰芯片却显示"干扰次数"） | 零值项过滤；但保留"打在本体上 0"这类**核心项**，因为 0 本身就是结论 |
| 4 | 曲线只有刻度没有轴标题，不知道横纵轴是什么 | 补上"生命值 / 回合数"轴标题 |

| 7 | 第一章学会"堆护盾"后，第二章仍然堆护盾就能过，缺少"换答案"的时刻 | 新增**破甲**机制：无视护盾与缓冲直接扣血，让护盾流在第二章明确失效 |
| 8 | 破盾芯片在第一章用过之后就没用了 | 第一章精英与第二章普通关**都保留护盾** |
| 9 | 只有首通奖励 + 资源投错会卡死 | 每个部位加**重置并全额返还**，同时作为死局保护 |
| 10 | 破阵模块是 1-2 的唯一解，但解锁价和其它芯片一样贵，容易变成"卡关"而不是"取舍" | 破阵解锁价单独降为 **1** |
| 11 | **结算口径 bug**（回归脚本抓到）：破阵让"击碎的护盾值"大于"实际投入的伤害"，两者混在同一根条里导致总量不符 | 新增"伤害投向"口径，保证分项之和恒等于总量；"击碎护盾值"降级到「其它记录」 |
| 12 | 早期血量曲线上，敌方的护盾图标会串到改造者的曲线上 | 效果标记按侧分离（改造者侧 / 敌方侧两个独立数组） |

### 4.4 为真人盲测准备的记录表（待执行）

**流程**：给试玩者链接，说一句"这是一个养成小游戏，你随便玩"，**不解释任何规则**，然后只观察、不提示。建议 8–10 分钟。

| 观察项 | 为什么要看它 |
|---|---|
| 从打开到第一次点击的秒数 | 首屏是否足够聚焦（理想：< 5 秒，因为只有一个按钮） |
| 打完 1-1 后第一个点的是什么 | 验证"先给问题再给工具"是否奏效（期望：点返回，然后注意到左侧新出现的养成板块） |
| 1-2 失败后，先看结算的哪一块 | **本次最想验证的一条**：期望是先看第一根堆叠条 |
| 从看到结算到做出改造决定的秒数 | 结算的可读性（期望：< 30 秒能说出"我的伤害被盾吃了"） |
| 能否说出自己放弃了什么 | 取舍是否真实（期望能说出"我把 X 卸下来装了 Y"） |
| 进第二章后是否注意到 `🪓破甲` 标记 | 敌人意图公开是否被读到 |
| 有没有用过「重置部位」 | 试错成本是否真的降到 0 |
| 哪个决策点停留最久 | 定位信息不足的地方 |
| 有没有出现"不知道该干什么"的空转 | 目标感是否断裂 |

**已预设的失败判定**：如果试玩者在 1-2 失败后**无法从结算得出"输出被护盾吃掉了"**，那么本方案的核心假设（堆叠条足以替代提示）就不成立，需要回到"是否给更强的数据对比"这一层重新设计——而不是加一句提示了事。

## 五、AI 使用说明（对应题目规则 1）

### 5.1 使用了什么

- **AI 对话式协作工具**：用于把我的设计意图落成代码、生成 HTML/CSS/JS 实现、编写调参与回归脚本、整理文档排版。
- **未使用**任何游戏引擎、UI 框架、组件库、付费模板或第三方美术素材。原型是原生 HTML/CSS/JS 单文件。
- **素材**：角色立绘为网络参考图（已裁去右下角水印），**仅作占位**，非本人原创也非最终美术；这一点已在 2.5 标注。

### 5.2 哪些内容由我独立完成（也是我能在面试中解释和现场修改的部分）

**全部设计决策由我做出**，包括：

1. **命题解法的整体思路**：把"目标感"落在 `卡点 → 调整 → 验证` 这条回路上，而不是靠任务列表或引导。
2. **系统结构**：三部位 × （固定主动 + 被动栏）；主动固定只能强化、被动只有两级；手臂/躯干各压到 1 格。
3. **每一条机制的设计意图**：破甲为什么要无视护盾与缓冲（让第一章的解法在第二章明确失效）；破阵为什么单独定价 1（它是唯一解，门槛必须低到"看懂就买得起"）；为什么删掉随机（让改造前后可干净对比）。
4. **经济结构**：双资源分工、仅首通奖励、躯体材料只从精英关产出且逐章递减、总量与待开槽位数严格相等。
5. **章节考点编排**：第一章护盾 / 第二章破甲 / 第三章减益，以及"第一章精英与第二章普通关都保留护盾"这条避免破盾芯片过早淘汰的安排。
6. **结算的信息架构**：删掉过程、改两根堆叠条、零值项过滤规则、哪些核心项即便为 0 也要保留。
7. **渐进式展开的时序**：首屏只给一个按钮，通过首关并**返回后**才展开养成板块。
8. **全部数值的目标与验收标准**：每关"哪些配装应该过、哪些应该败"这张约束表是我定的（它等价于关卡的设计意图）；AI 负责在约束下搜参数。

**AI 主要承担的是**：把上述决策翻译成代码、按我给定的约束表搜索满足条件的数值、编写机械校验脚本、以及文档的组织与排版。

### 5.3 数值是怎么定下来的（这一段是本方案的方法论，也是我最愿意在面试时展开的部分）

数值不是手调的，是**先写验收条件、再求解**：

1. 我先为每一关写一张**约束表**：这一关"应该被哪些配装通过、应该被哪些配装挡住"。这张表本身就是关卡的设计意图（例如 2-1 要求"缓冲装甲、硬抗 Lv.2、硬抗 Lv.3 全部失败，生体再生通过"——这就是"破甲让护盾流失效"的形式化表达）。
2. 然后对每关做网格搜索（敌人 HP × 攻击强度 × 护盾值），在满足全部约束的解里，按"胜负余量 + 回合节奏"打分取优。
3. 若无解，用诊断脚本输出"每一行约束被挡住的次数"，直接定位是哪两条互相矛盾。

**过程中真实遇到并解决的矛盾**（可以现场复盘）：
- 曾同时要求"反应装甲能过 2-2"和"重拳强化不能过 2-2"——两者都是加伤路线，不可能同时成立。诊断脚本一眼指出后，改为把反应装甲列为 2-2 的第二条合法解（与再生² 二选一，因为躯干只有 1 格）。
- 护盾关的敌人 HP 必须压低（护盾才是它真正的血量），否则搜不出解。1-2 最终是"42 HP + 每回合 26 护盾"这种极端配置。
- 打分函数一开始没有节奏项，搜出来的是"磨到 15 回合超时"或"3 回合速战"的畸形解，后来加了"通关须 ≤13 回合 + 超时判负扣分"才正常。
- 只有单条通过约束的关卡（1-1）不会被收敛（求解器会一路抬高 HP），这一关的数值是手工定的。
